# _inbox — Staging, kein Archiv

Rohmaterial, das noch destilliert werden muss: Links, Notizschnipsel, Exporte, PDFs.

**Der Ablauf ist immer derselbe:** Capture → Destillieren → **Rohdatei löschen.** Was hier
liegen bleibt, ist kein Wissen, sondern ein Vorwurf.

Der Inhalt dieses Ordners ist per `.gitignore` von der Versionierung ausgenommen — nur diese
README wird committet. Sensibles (Befunde, Verträge, alles mit Identifikatoren) gehört auch
lokal geschwärzt oder gar nicht erst hierher.
