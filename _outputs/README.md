# _outputs — Deliverables, kein Wissen

Hier landen Reports, Audits, Exporte und Health-Sweeps, die ein Agent erzeugt.

**Reports raus, Erkenntnisse rein:** Was davon durable ist, wird ins passende `okf/`-Konzept
destilliert. Die Report-Datei selbst gehört nie ins `okf/` und nie in den Repo-Root.

Der Inhalt dieses Ordners ist per `.gitignore` von der Versionierung ausgenommen — nur diese
README wird committet.
